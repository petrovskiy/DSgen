# Дизайн-система DSgen (сам продукт)

**Версия:** 0.1
**Дата:** 2026-08-05
**Статус:** Draft
**Связано:** PRD (US-002, US-003), варфреймы (screen-start/editor/export).

---

## Принцип (конституция)

> Контент — главный герой. UI не спорит с контентом: холодный холст из палитры «Тихий синий», сдержанные акценты, заголовки на Tenor Sans, текст на Manrope. Превью дизайн-시스템 пользователя должно выделяться на этом чистом фоне.

**Правила-основы:**
- Ничто не отвлекает от контента и превью.
- Светлая тема: белый фон + холодные тени, сине-серый подтон.
- Tenor Sans для заголовков, Manrope для body — минималистичный характер.
- Холодные приглушённые акценты, никаких лишних деталей.

## 1. Дизайн-токены (источник правды)

### Цвета (светлая тема — «Тихий синий»)

| Роль | Токен | Значение | Назначение |
|------|-------|----------|-----------|
| Фон страницы | `--bg` | `#FFFFFF` | Основной холст |
| Поверхность | `--surface` | `#F7F9FC` | Вложенные блоки (холодный off-white) |
| Поверхность повышенная | `--surface-2` | `#eef2f7` | Ховеры, выделение |
| Основной текст | `--text` | `#1F3040` | Заголовки, основной контент (холодный тёмно-синий) |
| Вторичный текст | `--text-secondary` | `#4B6B8A` | Подписи, описания (стальной) |
| Третичный текст | `--text-muted` | `#8096ad` | Плейсхолдеры, серо-голубой |
| Границы (лёгкие) | `--border` | `#e4e6e8` | Инпуты, разделители |
| Акцент-приглушённый | `--accent` | `#4B6B8A` | Кнопки primary, ссылки (стальной синий) |
| Акцент-hover | `--accent-hover` | `#35516d` | Ховер акцента (глубокий синий) |
| Акцент-фон | `--accent-soft` | `#e4e9ed` | Подложка акцента, бейджи |
| Success | `--success` | `#3F6212` | Успех |
| Warning | `--warning` | `#92400E` | Предупреждение |
| Danger | `--danger` | `#9A3412` | Ошибка |

**Контраст:** все текстовые пары проходят WCAG AA (≥4.5:1 для обычного текста).

### Тени (холодные, сине-серый подтон)

| Токен | Значение (характер) | Применение |
|-------|---------------------|-----------|
| `--shadow-subtle` | мягкая, холодный подтон `rgba(31,48,64,0.06)` | Карточки, подъём при ховере |
| `--shadow-medium` | `rgba(31,48,64,0.08)` | Модалки, дропдауны |
| `--shadow-focus` | холодный ореол акцента `rgba(75,107,138,0.18)` | Фокус на интерактивных |

### Типографика
- **Заголовки:** **Tenor Sans** (Google Fonts), элегантный антиквенный гротеск. Вес: **400**.
- **Body / UI:** **Manrope** (Google Fonts), современный гротеск. Веса: **300 / 400 / 500 / 600**.
- Интерлиньяж: 1.5 для текста, 1.15 для заголовков.
- Letter-spacing: −0.03em для крупных заголовков, 0 для body.

## 3. Компоненты редактора

### Кнопки

| Вариант | Стиль | Hover | Focus | Disabled |
|---------|-------|-------|-------|----------|
| **Primary** | `--accent` фон, белый текст, radius 8 | `--accent-hover` | `--shadow-focus` | фон `#E7E5E4`, текст `#A8A29E` |
| **Secondary** | белая, тонкая тёплая тень, `--text` | подъём `--shadow-subtle` | `--shadow-focus` | приглушение |
| **Ghost** | без фона, текст-акцент | `--surface-2` | `--shadow-focus` | `--text-muted` |

Высота 36px, padding `0 16px`, не жирный (400–500). «Ненавязчивые»: primary не кричит, secondary — основной рабочий вариант.

### Карточка пресета (Старт)
- Белая поверхность, `--shadow-subtle`, radius 12.
- Внутри мини-превью: полоска палитры, образец шрифта «Аа Bb», мини-кнопки (●/○).
- Hover: подъём (`--shadow-medium`), лёгкая подсветка.
- Selected: тонкая тёплая рамка акцента.

### Аккордеон токенов (Редактор)
- Тонкие разделители `--border`, без жирности.
- Заголовок группы — `--text-subheading` (18/500), не жирный.
- Контент раскрыт: `--surface` подложка, спокойное скругление.

### Инпуты и пикеры цвета
- Лёгкая рамка `--border` (1px), радиус 8, фон белый.
- Focus: `--shadow-focus` (+ рамка акцента).
- Плейсхолдер: `--text-muted`.

### Модалка экспорта
- Поверхность белая, `--shadow-medium`, радиус 16.
- Заголовок `--text-title` (24/400).
- Отступы: `--space-6` (24px) по краям.

### Превью-холст
- Нейтральная `--surface` подложка (`#FAFAF9`), без рамок.
- Служит контрастным фоном, на котором выделяется дизайн-система пользователя.

## 4. Правила для агента (фрагмент AGENTS.md для DSgen)

> Ниже перечень правил, которые будут включены в файл правил для ИИ-агента, работающего над UI DSgen.

- Фон только `--bg` (`#FFFFFF`) или `--surface`; запрещены насыщенные/тёмные/неоновые фоны.
- Текст — тёплый графит `--text`; для акцентов use `--accent`, не сырые HEX.
- Шрифт Manrope, веса ≤600; запрещены жирные 700+ и декоративные семейства.
- Тени — тёплые токены `--shadow-*`; запрещены холодные серые тени и «жёсткие» рамки для объёма.
- Кнопки: приоритет Secondary/Ghost; Primary только для одного главного действия на экране.
- Радиусы и отступы — только из токенов (4px сетка, радиусы 8/12/16).
- Все текстовые пары — контраст не хуже WCAG AA.

### Анти-паттерны (чего НЕ делать)
- ❌ Холодные фоны и тени (`#1E293B`, синий/серый холодный подтон).
- ❌ Насыщенные/неоновые акценты (синий `#3B82F6`, фиолетовый `#8B5CF6`).
- ❌ Жирный крупный текст (700+/32px+ для обычного контента).
- ❌ Много рамок, «коробочный» вид вместо тёплых теней.
- ❌ Карточки с сильной тенью/рельефом, отвлекающим от контента.

## 5. Связи и применение
- Токены (раздел 1) → основа будущего экспорта `globals.css` + `tailwind.config.ts` для самого DSgen.
- Компоненты (раздел 3) — для сборки варфреймов (screen-start/editor/export).
- Правила для агента (раздел 4) — фрагмент, который войдёт в `docs/AGENTS.md` при старте разработки.

### Открытые вопросы
- Тёмная тема для UI самого DSgen — пока только светлая (вне скоупа MVP, как и в PRD).
- Не сет-контраст для небольших акцентов (`--text-muted` на белом) — финализировать на вёрстке.

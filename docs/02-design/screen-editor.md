# Варфрейм: Экран 2 — Редактор

**Связано:** US-001, US-003, US-004; FR1, FR2, FR4, FR5, FR11, FR12.
**Уровень:** средний (ASCII, зоны + ключевые элементы).
**Назначение:** ручное заполнение или генерация всех токенов, живой предпросмотр, точечная перегенерация элементов.

## Легенда зон

| № | Зона | Содержимое |
|---|------|-----------|
| 0 | Верхняя панель | Назад, название экрана, кнопка «Сгенерировать всё» (заполняет все группы токенов значениями из генератора), «Сброс», выбор Google Fonts |
| 1 | Группа «Цвета» | Базовый цвет (пикер), выбор гармонии (аналог/комплемент/триада/тетрада/монохром), сваши палитры, индикатор контраста WCAG (AA/AAA) на паре, кнопка ↻ перегенерировать палитру |
| 2 | Живое превью | Дефолтный шаблон: карточка (заголовок, текст, кнопка), форма (инпут + кнопка), иконки. Все правки токенов мгновенно отражаются |
| 3 | Аккордеон групп | Типографика, Отступы, Радиусы, Тени, Z-index, Брейкпоинты — разворачиваются и редактируются |
| 4 | Сброс | Возврат к исходным значениям пресета |
| 5 | Нижняя панель | Назад на Старт, Сохранить (localStorage), Скачать архив (модалка экспорта) |

## Взаимодействия и состояния

### Режимы заполнения (два старта)
1. **Вручную** — пользователь правит любую группу токенов в панелях 1 и 3.
2. **Сгенерировать** — кнопка «Генер. всё» (зона 0) или ↻ в группе «Цвета»: генератор по цветовому кругу заполняет **все** группы (цвета, типографику, отступы, радиусы, тени, z-index, брейкпоинты). После генерации пользователь донастраивает вручную (гипотеза H2: «генератор 80%, человек докручивает 20%»).

### Точечная перегенерация (FR12)
- В превью (зона 2) у элемента появляется кнопка `[+]` при наведении/выборе.
- «Перегенерировать…» → выбор: кнопка / карточка / инпут → перегенерируется **только выбранный элемент**, остальная система не меняется.
- Результат сразу виден в превью.

### Контраст (FR2)
- Индикатор «контраст ▓ AA ▓ AAA» у палитры: подсвечивает, проходит ли пара по WCAG (светлый фон/светлый текст — блокировка/предупреждение).

### Состояния
- **Пустой проект** (открыт без пресета): панели пусты, превью показывает плейсхолдеры, кнопка «Скачать архив» заблокирована с подсказкой «Выберите пресет или сгенерируйте».
- **Сохранение:** после «Сохранить» — метка «Изменено» снимается, состояние пишется в localStorage (FR13).

# Варфрейм: Редактирование дизайн-системы

**Связано:** US-001, US-003, US-004; FR1, FR2, FR4, FR5, FR11, FR12.
**Уровень:** средний (ASCII, зоны + ключевые элементы).
**Назначение:** пошаговый выбор и настройка компонентов дизайн-системы через визард (шаги 2–4).

**Важно:** вместо классического редактора «аккордеон слева + превью справа» прототип разбивает процесс на три отдельных шага визарда: Палитра, Шрифты, Превью.

---

## Шаг 2 — Палитра

```
Пользователь выбирает готовую цветовую палитру из галереи.

ГАЛЕРЕЯ ПАЛИТР (фильтруется по выбранной концепции)
┌──────────────────────────────┐ ┌──────────────────────────────┐
│ ████████ поверхность ████ ██ │ │ ████████ поверхность ████ ██ │
│ Графитовый порядок           │ │ Холодный сланец              │
└──────────────────────────────┘ └──────────────────────────────┘
```

### Взаимодействия
- **Фильтрация:** палитры делятся на «Рекомендуемые» (основные для концепции) и «Допустимые» (альтернативы). Состав определяется полями `paletteIds` и `allowedPaletteIds` в концепции.
- **Карточка:** показывает 5 цветовых полос пропорционально роли (фон 32% / поверхность 22% / граница 10% / акцент 18% / текст 18%).
- **Тёмная тема оболочки:** карточки адаптируются — если оболочка тёмная, а палитра светлая, показывается альтернативная тёмная версия (и наоборот).
- **Клик:** выбирает палитру, сбрасывает переопределение темы (`wizard.themeMode = null`).

### Семантический анализ палитры
Каждая палитра (5 цветов) автоматически анализируется:
1. Определяется mode: `light` или `dark` (по распределению яркости).
2. Нейтральные цвета распределяются: светлые → фон/поверхность, тёмные → текст.
3. Хроматические цвета → акцент.
4. Границы вычисляются как mix фона и текста.
5. Семантические цвета (success/warning/error/info) подбираются из предопределённого набора.
6. Генерируется альтернативная тема через `generateAltTheme()` — инвертирует светлую в тёмную и наоборот.

### Данные
- 40+ палитр в `palettes.json`, каждая с 5 HEX-цветами.
- Некоторые палитры имеют предопределённый `colorSystem` (ручная семантика), остальные анализируются на лету.

## Шаг 3 — Шрифты

```
Пользователь выбирает шрифтовую пару из галереи + видит живой предпросмотр.

ЖИВОЙ ПРЕДПРОСМОТР
┌──────────────────────────────────────────────┐
│  ЗАГОЛОВОК БРЕНДА                            │ ← заголовок в выбранном шрифте
│  Обычный текст: читаемый абзац, показывающий   │ ← тело в выбранном шрифте
│  шрифт основного контента. Кириллица.          │
└──────────────────────────────────────────────┘

ШРИФТОВЫЕ ПАРЫ (фильтр по концепции)
┌──────────────────────────────┐ ┌──────────────────────────────┐
│ Tenor Sans + Manrope         │ │ Yeseva One + Manrope         │
│ Заголовок                    │ │ Заголовок                    │
│ Основной текст               │ │ Основной текст               │
│ Чистая, минималистичная      │ │ Изящный заголовок, ...       │
└──────────────────────────────┘ └──────────────────────────────┘
```

### Взаимодействия
- **Фильтрация:** пары делятся на «Рекомендуемые» и «Альтернативы» (`fontPairIds` / `allowedFontPairIds` в концепции).
- **Карточка:** бейдж с названием, образец заголовка в `font-family` с весом `hw`, образец текста в `font-family` с весом `bw`, описание `note`.
- **Клик:** выбирает пару, подгружает шрифты из Google Fonts, обновляет предпросмотр.
- **Предпросмотр:** блок над галереей показывает живой образец заголовка и текста в выбранных шрифтах. При скролле прилипает к хедеру (sticky) через IntersectionObserver.

### Данные
- 32 шрифтовые пары в `fonts.json` (встроены inline в app.js на случай CORS).
- Каждая пара: `heading` (семейство + вес `hw`), `body` (семейство + вес `bw`).
- 40+ шрифтов Google Fonts с полными CSS-ссылками (веса 300–700).

### Компоненты превью-холста

**Десктопный шаблон (Web):**
- Header: логотип DSgen, навигация (Возможности, Цены, О нас), кнопка «Войти»
- Hero: eyebrow «Платформа», заголовок, описание, две кнопки (Primary + Secondary)
- Статистика: 3 карточки (базовый радиус, масштаб заг/текст, контраст WCAG)
- Цитата в блоке с левой accent-рамкой
- Карточки: Палитра (цветные кружки + mode) и Типографика (Aa Бб)
- Форма: инпут «Имя проекта» + кнопка «Создать»
- Список: токены (Палитра / Типографика / Отступы)
- Footer: текст «Сгенерировано в DSgen · палитра · концепция»

**Мобильный шаблон:**
- Phone frame (device mockup)
- Status bar (9:41, сигнал)
- Header: название «Мой APP» + иконка-аватар
- Hero: eyebrow, заголовок, описание
- Карточка: прогресс-бар с иконкой и текстом
- Форма: инпут «Имя»
- Кнопки: Primary «Отправить» + Secondary «Отмена»
- Bottom navigation: Главная, Поиск, Профиль (с иконками)

### Drawer (редактирование на шаге 4)

**FAB-кнопка ✏️** — плавающая кнопка в правом нижнем углу, открывает drawer.

**Содержимое drawer:**
1. **Шрифты** — два селекта (заголовок / текст). Все 40+ шрифтов Google Fonts. При смене шрифт подгружается и превью перерисовывается.
2. **Палитра** — сворачиваемая секция с сеткой цветных кружков (все 40+ палитр). Активная палитра подсвечена.
   - **Кнопка «Вставить из Colors CO»** — парсит буфер обмена в формате `--name: #HEX;` (CSS-переменные), добавляет новую палитру в список и активирует её.
3. **Концепция** — выпадающий список всех 10 концепций.

Все изменения в drawer мгновенно применяются к превью (перерисовка `renderStep4()`).

### Переключение темы превью
- Слайдер в строке табов переключает `wizard.themeMode` между `'light'` и `'dark'`.
- Если выбранная тема противоположна primaryMode палитры, используется альтернативная тема (`generateAltTheme` → `_colorSystemAlt`).

### Табы превью
- «Сайт» / «Мобильное приложение» — переключают видимость блоков `#final-preview` и `#mobile-preview`.

## Связанные сценарии (USERFLOW)
- Happy-path: шаг 2 → выбор палитры → шаг 3 → выбор шрифтов → шаг 4 → просмотр → скачать.
- Ветвление: редактирование через drawer без возврата на предыдущие шаги.
- Edge-case: вставка цветов из буфера (нестандартная палитра).

# Варфрейм: Экспорт дизайн-системы

**Связано:** US-005; FR6–FR10, FR14, FR15.
**Уровень:** средний (ASCII, зоны + ключевые элементы).
**Назначение:** генерация и скачивание ZIP-архива с дизайн-системой.

**Важно:** в текущем прототипе экспорт реализован как кнопка «Скачать архив» на шаге 4 визарда (без модального окна с выбором платформ). При переходе к React-приложению планируется вернуть модальное окно с выбором целевых платформ.

---

## Текущая реализация (прототип)

### Кнопка экспорта
- Расположена на шаге 4 (Превью), в инфо-бейдже рядом с выбранной палитрой, шрифтами и концепцией.
- При клике сразу генерирует и скачивает ZIP-архив (без промежуточного диалога).

### Структура ZIP-архива

```
design-system.zip
└── .design/
    ├── design.md        — полная MD-спека (29 разделов)
    ├── tokens.json      — JSON-токены (цвета, типографика, spacing, радиусы, тени, эффекты)
    └── components.md    — CSS-компоненты (кнопки, инпуты, карточки, бейджи, навигация, модалки)
                         — светлая + тёмная тема
```

### Содержимое файлов

**design.md** (29 разделов):
1. Идентичность дизайна
2. Принципы дизайна
3. Цветовая система (brand, фон, текст, границы, семантика, палитра)
4. Типографика (семейства, шкала Display—Caption)
5. Система отступов (сетка на базе концепта)
6. Разметка (контейнер, сетка, брейкпоинты)
7. Скругление углов
8. Границы и разделители
9. Тени и элевация
10. Компоненты (кнопки Primary/Secondary/Ghost/Destructive, инпуты, карточки, бейджи, навигация, модалки)
11. Иконография
12. Изображения
13. Анимация и движение
14. Адаптивное поведение
15. Тёмная / светлая тема (полные токены для обеих)
16. Доступность (accessibility)
17. Контент и плотность UI
18. Визуальные эффекты (blur, glassmorphism, noise, glow)
19. Дизайн-паттерны
20. Структура страницы
21. Состояния UI (9 состояний)
22. Визуализация данных
23. Дизайн-токены (JSON-фрагмент)
24. Правила для AI-агента (обязан / запрещено)
25. Правило переиспользования компонентов
26. Чек-лист визуального QA
27. Политика изменений
28. Текущие дизайн-решения
29. Статус дизайн-системы

**tokens.json** — машиночитаемый JSON:
- `meta`: имя, палитра, шрифты, концепция, дата
- `color.active` / `color.light` / `color.dark`: полные цветовые токены для каждой темы
- `typography`: шрифты, начертания, шкала размеров
- `spacing`: единица и полная шкала
- `radius`: 5 значений (none, sm, md, lg, full)
- `shadow.style`: тип теней концепции
- `effects`, `borders`, `animation`, `density`, `icons`, `layout`: styleConfig концепции

**components.md** — CSS с HTML-примерами:
- Кнопки (4 варианта)
- Инпуты (с состояниями error/success)
- Карточки (с поддержкой glassmorphism, glow, noise)
- Бейджи (5 вариантов)
- Навигация (navbar)
- Модалки
- Светлая тема (`:root`) и тёмная тема (`:root[data-theme="dark"]`)
- Glass Card (при включённых эффектах)

### Взаимодействия
- **Клик по кнопке «Скачать архив»** → JSZip генерирует ZIP в памяти → скачивание через Blob URL.
- **Тост-уведомление:** «Архив design-system.zip скачан».
- **Пустой проект:** кнопка доступна всегда (выбор по умолчанию гарантирует, что проект не пуст).

## Планируемая реализация (React-приложение)

### Модальное окно экспорта

```
+───────────────────────────────────────────────────────────────+
|  0  Экспорт дизайн-системы                          [✕ Закрыть]|
├───────────────────────────────────────────────────────────────┤
|  1  Выберите платформы:                                       |
|     [✓] Web        (CSS + Tailwind)                           |
|     [ ] Flutter    (Dart: токены + ThemeData)                 |
|     [ ] Swift      (SwiftUI: DesignSystem.swift)              |
|                                                               |
|  2  Всегда в архиве:  MD-спека (design-system.md)             |
|     + правила для агента (AGENTS.md)                          |
|                                                               |
|  3  Шрифты:                                                   |
|     (●) Ссылка на Google CDN   ( ) Скачать woff2              |
|                                                               |
|  4  Структура архива:                                         |
|     design-system.zip                                         |
|     ├─ tokens/      ▸colors, typography, spacing, ...         |
|     ├─ styles/      ▸globals.css, tailwind.config.ts          |
|     ├─ components/  ▸button, card, input                      |
|     ├─ fonts/       ▸README + ссылка на CDN                   |
|     └─ docs/        ▸design-system.md, AGENTS.md              |
|                                                               |
|  5  [Отмена]                            [Скачать ZIP]        |
+───────────────────────────────────────────────────────────────+
```

### Легенда зон (план)

| № | Зона | Содержимое |
|---|------|-----------|
| 0 | Заголовок модалки | Название, кнопка закрытия ✕ |
| 1 | Выбор платформ | Чекбоксы Web / Flutter / Swift |
| 2 | Постоянные файлы | MD-спека + AGENTS.md — всегда в архиве |
| 3 | Шрифты | Радио: ссылка Google CDN (по умолчанию) или скачивание woff2 |
| 4 | Структура архива | Превью файлового дерева |
| 5 | Действия | «Отмена» и «Скачать ZIP» |

## Связанные сценарии (USERFLOW)
- Happy-path: шаг 4 → кнопка «Скачать архив» → ZIP скачан.
- План: шаг 4 → кнопка «Скачать архив» → модалка → выбор платформ → ZIP скачан.
- Edge-case: ни одна платформа не выбрана → кнопка disabled.

## Легенда зон

| № | Зона | Содержимое |
|---|------|-----------|
| 0 | Заголовок модалки | Название, кнопка закрытия ✕ |
| 1 | Выбор платформ | Чекбоксы Web / Flutter / Swift |
| 2 | Постоянные файлы | MD-спека + AGENTS.md — всегда в архиве (приоритет: MD-спека → правила агента → код, из Discovery) |
| 3 | Шрифты | Радио: ссылка Google CDN (по умолчанию) или скачивание woff2 (опция) |
| 4 | Структура архива | Превью файлового дерева, которое будет скачано |
| 5 | Действия | «Отмена» и «Скачать ZIP» |

## Взаимодействия и состояния

- **Ни одна платформа не выбрана** → кнопка «Скачать ZIP» disabled, подсказка «Выберите хотя бы одну платформу».
- **Выбрано ≥1 платформы** → кнопка активна.
- **Сборка:** общие файлы (tokens/*.json, docs/) + файлы выбранных платформ; шрифты по выбору зоны 3.
- **Ошибка генерации (jszip)** → повторная попытка + сообщение об ошибке (не закрывать проект).
- **Пустой проект** → экспорт недоступен, подсказка «Выберите пресет или сгенерируйте» (экран не открывается из редактора при пустых токенах).
- **Отмена / ✕** → возврат в Редактор без изменений.

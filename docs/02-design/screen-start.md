# Варфрейм: Экран 1 — Старт (Галерея пресетов)

**Связано:** US-002, US-006; FR3, FR13.
**Уровень:** средний (ASCII, зоны + ключевые элементы).
**Назначение:** выбор готового стиля из галереи или запуск генерации; восстановление сохранённого проекта.

## Легенда зон

| № | Зона | Содержимое |
|---|------|-----------|
| 0 | Шапка | Логотип DSgen; меню «Восстановить проект» (доступно при наличии сохранённого проекта) |
| 1 | Шапка, правая часть | Кнопки настроек / пусто на MVP |
| 2–3 | Галерея пресетов | Карточки стилей (grid 3×2). Каждая мини-плашка: образец палитры, образец шрифта «Аа Bb», мини-кнопки (●/○) — узкое превью `font + color + элемент` |
| 4 | Главный CTA | Большая кнопка «Начать генерацию» — открывает Редактор |
| 5 | Баннер восстановления | Показывается только при обнаружении проекта в localStorage: «Продолжить» / «Начать новый» |

---

## Взаимодействия и состояния

- **Нет сохранённого проекта** → баннер восстановления скрыт; «Начать генерацию» — единственный CTA.
- **Есть сохранённый проект** → баннер 5 виден; «Продолжить» восстанавливает состояние, «Начать новый» очищает и проходит на Старт.
- **Выбор пресета** = фильтр поколения: открывает Редактор с токенами этого стиля (US-002).
- **«Начать генерацию» без выбора пресета** → Редактор открывается со «случайным» пресетом (генерация происходит уже в Редакторе).
- **Клик по карточке** → подсветка выбранной (selected state), повторный клик → переход в Редактор.

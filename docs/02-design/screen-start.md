# Варфрейм: Экран 1 — Визард генерации

**Связано:** US-002, US-006; FR3, FR13.
**Уровень:** средний (ASCII, зоны + ключевые элементы).
**Назначение:** пошаговый мастер создания дизайн-системы: выбор концепции, палитры, шрифтов и предпросмотр результата.

**Важно:** вместо трёх отдельных экранов (Старт → Редактор → Экспорт) прототип реализован как единый 4-шаговый визард с общим хедером и футером.

## Взаимодействия и состояния

### Навигация
- **Линейный флоу:** пользователь проходит шаги 1→2→3→4 последовательно.
- **Кнопка «Назад»:** возвращает на предыдущий шаг. На шаге 1 — «Отмена» (остаётся на шаге 1).
- **Индикатор шагов** в хедере подсвечивает текущий шаг.

### Выбор концепции (шаг 1)
- **Клик по карточке** → выбирает концепцию, сбрасывает палитру и шрифты на рекомендуемые для этой концепции.
- **Карточки стилизованы:** фон, шрифт, цвета и тени отображают характер концепции. Учитывают тёмную тему оболочки.

### Выбор палитры (шаг 2)
- Фильтруется по выбранной концепции (рекомендуемые + допустимые).
- Каждая карточка показывает автоматически проанализированную семантическую раскладку (фон, поверхность, граница, акцент, текст).
- Учитывает тёмную тему оболочки (авто-переключение темы карточки).

### Выбор шрифтов (шаг 3)
- Фильтруется по выбранной концепции (рекомендуемые + альтернативы).
- Живой предпросмотр в блоке сверху — шрифты подгружаются из Google Fonts динамически.
- Карточка показывает оба шрифта в их начертании.

### Предпросмотр (шаг 4)
- **Табы:** переключение между десктопным (сайт) и мобильным превью.
- **Слайдер темы:** переключает светлую/тёмную тему сгенерированной дизайн-системы.
- **FAB ✏️:** открывает/закрывает drawer редактирования.
- **Drawer:** позволяет изменить любой аспект системы без возврата на предыдущие шаги:
  - Сменить шрифты (выпадающие списки)
  - Сменить палитру (сетка кружков, все 40+)
  - Сменить концепцию (выпадающий список)
  - Вставить цвета из буфера (формат Colors CO: `--name: #HEX;`)
- **Скачать архив:** генерирует ZIP с `.design/design.md` + `tokens.json` + `components.md`.

### Тёмная тема оболочки
- Переключатель в хедере (☀/🌙), сохраняется в localStorage.
- Все карточки концепций и палитр адаптируются под тему оболочки.

### Состояния
- **Пустой выбор (шаг 1):** первая концепция выбрана по умолчанию, палитра и шрифты сбрасываются к её рекомендуемым.
- **Смена концепции:** сбрасывает палитру и шрифты, если они не входят в допустимые для новой концепции.

## Связанные сценарии (USERFLOW)
- Happy-path: линейный проход 1→2→3→4 → скачать ZIP.
- Ветвление: смена концепции на шаге 4 через drawer (без возврата).
- Edge-case: вставка цветов из буфера на шаге 4.

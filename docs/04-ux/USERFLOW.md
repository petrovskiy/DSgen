## 1. Happy-path — новый пользователь

**Цель:** за несколько минут сгенерировать дизайн-систему и скачать ZIP-архив.
**Предусловия:** новый пользователь, localStorage пуст.
**Связано:** US-001, US-002, US-003, US-004, US-005; FR1–FR10.

```
[Экран Старт]
1. Вход → отсутствует сохранённый проект → показать панель пресетов + кнопку «Сгенерировать».
2. Пользователь выбирает пресет ИЛИ нажимает «Сгенерировать случайно».
   └── Пресет: заполняет все токены стиля (цвета, типографика, spacing, radius, shadow, z-index, breakpoints).
   └── «Сгенерировать случайно»: базовый оттенок + гармония по цветовому кругу + проверка контраста.

[Экран Редактор]
3. Открывается редактор: токены слева, живой предпросмотр на дефолтном шаблоне справа (кнопка, карточка, форма, иконки). Изменения видны сразу (FR11).
4. Пользователь правит токены (Цвета / Типографика / Отступы / Радиусы / Тени / Z-index / Брейкпоинты).
   └── Не нравится конкретный элемент (например, кнопка) → «Перегенерировать кнопку» — перегенерируется только этот элемент, остальная система не меняется (FR12).
5. Пользователь открывает Google Fonts, ищет семейство, выбирает начертания → шрифты попадают в типографику.

[Экран Экспорт]
6. Нажимает «Скачать архив» → модальное окно выбора платформ.
7. Отмечает Web / Flutter / Swift → подтверждает → генерируется ZIP (tokens/, styles/, components/ P1, fonts/, docs/, AGENTS.md).
8. DOWNLOAD — ZIP сохранён. Фин.
   Исключения: см. раздел 5.

## 2. Ветвление A — Восстановление проекта

**Цель:** продолжить редактирование ранее сохранённого проекта.
**Предусловия:** в localStorage есть ранее сохранённый проект.
**Связано:** US-006; FR11.

```
1. Вход (открытие приложения) → чтение localStorage.
   └── Проект найден и валиден → показать предложение «Продолжить» / «Новый проект».
       - «Продолжить» → редактор с восстановленными токенами.
       - «Новый проект» → очистить состояние, перейти на [Экран Старт].
   └── Проект не найден → перейти на [Экран Старт] (happy-path).

Исключения:
- JSON повреждён / устаревшая схема → показать уведомление «Не удалось восстановить проект»,
  предложить «Новый проект»; при подтверждении очистить некорректные данные.
- Перезагрузка во время редактирования → состояние сохраняется только после явного действия
  (автосохранение вне скоупа MVP; см. раздел 5).
```

## 3. Ветвление B — Правка существующего пресета

**Цель:** взять готовый стиль и адаптировать под бренд.
**Предусловия:** пользователь на [Экране Старт] или [Экране Редактор].
**Связано:** US-002, US-003; FR3, FR4.

```
1. Пользователь выбирает пресет из панели → токены заполнены.
2. Открывается редактор → правила токены по группам.
3. После правок:
   └── «Сохранить» → состояние пишется в localStorage (проект теперь кастомный, метка «Изменено»).
   └── «Скачать архив» → перейти к экспорту (раздел 1, шаги 6–8).

Исключения:
- «Сброс» (возврат к исходным значениям пресета) → восстановить значения пресета; метка «Изменено» снимается.
- Пользователь правит, но не сохраняет и уходит → при переходе «Новый проект» или «Сменить пресет»
  запросить подтверждение потери изменений (см. раздел 4).
```

## 4. Ветвление C — Смена пресета

**Цель:** заменить текущую дизайн-систему на другой базовый стиль.
**Предусловия:** открыт [Экран Редактор], есть текущий проект.
**Связано:** US-002; FR3.

**Решение (принято):** пресет полностью заменяет все токены. Перед применением — подтверждение пользователя.

```
1. Нажимает «Сменить пресет» на панели.
2. Проверка: есть ли незакоммиченные изменения токенов.
   └── Изменений нет → применить новый пресет (полная замена токенов).
   └── Есть изменения → диалог: «Заменить текущие настройки новым пресетом?» [Заменить/Отмена].
       - «Заменить» → полная перезапись всех токенов новым пресетом.
       - «Отмена» → остаться на текущем проекте ( изменения сохраняются ).

Исключения:
- Пользователь нажимает «Сгенерировать случайно» при открытом проекте с правками
  → тот же диалог подтверждения (изменения будут заменены).
- Выбранный пресет недоступен/ошибка данных → уведомление, текущий проект не трогается.
```

## 5. Ветвление D — Экспорт с выбором платформ

**Цель:** сгенерировать архив под нужные платформы.
**Предусловия:** есть заполненные токены, открыто модальное окно экспорта.
**Связано:** US-005; FR6–FR10, FR14.

```
1. Нажимает «Скачать архив» → модальное окно экспорта.
2. Выбирает одну или несколько платформ: Web / Flutter / Swift.
   └── Выбрано ≥ 1 платформы → активна кнопка «Скачать ZIP».
   └── Не выбрано ни одной → кнопка заблокирована.
3. Система собирает общие файлы (tokens/*.json, docs/design-system.md, docs/AGENTS.md)
   + файлы выбранных платформ (globals.css, tailwind.config.ts / dart / swift).
4. Проверка шрифтов Google Fonts:
   └── Выбранные шрифты есть в библиотеке → в экспорт добавляется ссылка подключения через Google CDN
       (fonts/README.md с инструкцией); скачивание woff2 — опционально.
   └── Шрифты недоступны → предупреждение + fallback-список в документации.
5. Генерируется ZIP → файл скачивается.

Исключения:
- Ошибка генерации jszip / большой объём → повторная попытка, сообщение об ошибке.
- Отключённая сеть при загрузке шрифтов → экспорт без скачанных font-файлов, pdf README-инструкция.
- Пустой проект (нет токенов) → заблокировать экспорт и подсказать выбрать пресет.
```

## 6. Edge-cases (сводно)

| Ситуация | Поведение |
|----------|-----------|
| Пустой проект, попытка экспорта | Экспорт заблокирован, подсказка «Выберите пресет» |
| Повреждённый localStorage | Уведомление + предложение «Новый проект» |
| Ошибка jszip при сборке | Повторная попытка, сообщение об ошибке |
| Google Fonts API недоступен | Кэш каталога / fallback-список, graceful уведомление |
| Старый/несовместимый браузер | Минимальная поддержка современных браузеров; предупреждение о необходимости обновления |
| Перезагрузка до сохранения | В MVP изменения не автосохраняются; при «Новый/Сменить пресет» — диалог подтверждения |
| Ни одна платформа не выбрана | Кнопка «Скачать ZIP» заблокирована |
